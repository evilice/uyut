# Документация по оптимизации сайта «УЮТ»

Статический лендинг мастерской творчества «УЮТ» (Энгельс, ул. Маяковского, 47а):
`index.html` + юридические страницы, PHP-шлюз заявок `send.php` / `mail-settings.php`,
конфиг Apache `.htaccess`, изображения в `assets/`. Хостинг REG.RU (Linux + PHP),
деплой — загрузка содержимого папки через файловую панель, без сборки и без CI.

Этот каталог — рабочая документация: что уже сделано и почему, и постановка задач
по каждому незакрытому пункту.

Файлы не отправляются посетителям: доступ закрывает `docs/.htaccess` (`Require all denied`),
как и для `tools/` — проверено на реальном Apache (`docs/README.md` → 403, при этом
`index.html` и `assets/img/*.avif` отдаются 200 с корректными заголовками).

## Зачем это затевалось

21.11.2026 по главной странице была проведена диагностика: страница тянула **21.4 МБ**
изображений, сжатие и кэш на Apache не были включены вообще, каталог из 21 мастер-класса
существовал только в JS-массиве, а обе модальные окна были `div` без Escape и без ловушки
фокуса. Находки ранжировали в 8 приоритетов и закрывали по выбору владельца.

Все числа в документации — измеренные (Chromium через CDP, реальный `httpd:2.4` в Docker,
`gzip`/`du`/`identify`), а не оценочные. Там, где первоначальный вывод оказался неверным,
это отдельно оговорено ниже.

## Закрыто

### 1. Сжатие, кэш и доступы в `.htaccess`

Было 15 строк / 346 Б, стало ~70 строк / 3.1 КБ. Проверено на реальном Apache 2.4:

| Проверка | Результат |
|---|---|
| `mod_deflate` | CSS 41 482 → **9 819 Б** (4.2×); JS 8 513 → 1 086 Б |
| `Content-Encoding` | есть на html/css/js, нет на jpg (и не должен быть) |
| Без `Accept-Encoding` | 200, `Content-Length: 41482` — не ломается |
| css/js с `?v=` | `public, max-age=31536000, immutable` |
| jpg/png/webp/avif | `public, max-age=2592000` |
| html / `send.php` | `no-cache` / `no-store` |
| `ИНСТРУКЦИЯ_REG_RU.txt`, `*.bak`, `tools/*.py`, листинг папок | **403** |
| `robots.txt`, обычный `.txt` | **200** — проверялось специально |

Обычные `.txt` целиком не блокируются: первое правило блокировало вообще все `.txt`,
что молча убило бы будущий `robots.txt`. Отдельный риск для REG.RU: если там не окажется
`mod_deflate`/`mod_expires`, обёртка `<IfModule>` спасёт от 500, но сжатия не будет —
после заливки стоит проверить заголовки `curl`'ом.

### 2. Адаптивные изображения (главный выигрыш)

**Загружаемый вес картинок главной: 21 908 КБ → 1247 КБ, в 17.6 раза меньше.**
На десктопе DPR2 выбирается AVIF во всех 35 случаях, старых форматов не грузится ничего.

Конвейер в `tools/` (подробности в `tools/README.md`):

- `build-adapted-images.py` → `assets/img/<группа>/*-{ширина}.{avif,webp}` (105 файлов,
  5.8 МБ на хостинге), `assets/img/manifest.json`, `assets/js/images.js`.
- `wire-adapted-images.py` → идемпотентно переставляет `<picture>` в `index.html`
  (изначально 14 обёрток; после пункта 5 — 35, вместе с карточками каталога).

Ширины вариантов взяты не «красивыми числами», а из замеров реальных CSS-боксов каждой
картинки на 1920/1280/760/390, умноженных на DPR, с отсечкой по ширине исходника
(апскейл не генерируем). Формат выбран по бенчмарку на выборке 33.5 МБ:
994 КБ в JPEG, 622 КБ в WebP, **312 КБ в AVIF**.

Исходники в `assets/` **не тронуты** и остаются единственными полными копиями — не удалять.

### 3. Модальные окна на нативном `<dialog>`

`#modal` (форма заявки) и `#detailModal` (описание мастер-класса) переведены с `div`
на `<dialog>`: Escape, ловушка фокуса, инертность фона и возврат фокуса теперь даёт браузер,
а не рукописный код. Замерено до и после:

| Было | Стало |
|---|---|
| Escape не закрывал форму (`grep -c 'Escape' main.js` = 0) | закрывает, `body.lock` снимается |
| 92 focusable элемента фона доступны при открытом окне | фон инертен |
| стартовый фокус на `div.modal-card`, заголовок не озвучивался | фокус на `DIALOG`, `aria-labelledby` |
| `aria-hidden="true"` на открытом окне | убран (ломал AT) |
| бургер без состояния | `aria-expanded` + `aria-controls` |
| `×` без описания | `type="button"` + `aria-label` |

Побочно исправлен layout shift лайтбокса: было 0.1056 у оригинала, стало **0.0016**
(незагруженный `<img>` при `width:auto;height:auto` давал box 0×0 и смещение всего диалога).

### 4. SEO: canonical, OG, robots, sitemap, JSON-LD

Домен — `https://uyutengels.ru/`: HTTPS 200, `http://` → `https://` 301, а
`www.uyutengels.ru` отвечает 200 без редиректа — дубль хоста закрыт `canonical` на
без-www вариант. В `<head>` добавлены `canonical`, `theme-color`, `og:` + Twitter Card
и JSON-LD `LocalBusiness` (адрес, телефон, 4 соцсети; часы/координаты/рейтинг не
размечались — их значений нет в HTML). В корне: `robots.txt` (68 Б, пустой `Disallow:`
+ `Sitemap:`), `sitemap.xml` (4 URL, 509 Б) и `assets/img/og/og-1200x630.jpg`
(133 КБ, 1200×630) — превью для мессенджеров, генерируется `tools/build-og-image.py`
из фото входа. Favicon — три файла (16.5 КБ) из `tools/build-favicon.py`: монограмма
«У», потому что полный знак 403×474 в 16–32 px не читается.

`index.html` 68.1 КБ raw / 13.7 КБ gzip. JSON-LD и sitemap проверены парсером, все
новые файлы локально отдаются 200. На проде изменений пока нет (там `index.html`
от 17.10), чек-лист после заливки — в `04-seo-and-structured-data.md`.

### 5. Каталог мастер-классов в HTML, а не только в JS

21 карточка теперь статически лежит в `index.html` (источник истины —
`assets/data/workshops.json`, генератор — `tools/build-catalog.py`). Поисковик и
человек без JS видят предложение; фильтры переключают видимость готовых карточек,
а не пересобирают `innerHTML` (картинки не перезагружаются). У `.reveal` появился
фолбэк: без JS контент виден, при падении/задержке `main.js` — через 3 с.

Замеры: `grep -c 'work-card' index.html` = 21, `<picture>` = 35 (14 + 21 карточка);
на момент шага `index.html` был 63.7 КБ raw / 12.8 КБ gzip, `catalog.js` — 20.0 / 4.9 КБ
(актуальные размеры — в разделе «Текущие размеры»).
Диффы скриншотов 1920/1280/760/390 = **0 пикселей**, контрольная пара = 0.

### 8. Контроль версий

Репозиторий инициализирован, `.gitignore` закрывает `*.bak`/`*.orig`/`*.zip` и т.п.
Первый коммит — состояние после пунктов 1–3; remote `origin` — SSH
(`git@github.com:evilice/uyut.git`). `git checkout -- <файл>` работает, `git status`

## Правила сопровождения, которые появились вместе с правками

1. **После любых новых фото** — `python3 tools/build-adapted-images.py`, затем
   `python3 tools/build-catalog.py` (он сам вызывает `wire-adapted-images.py`).
   Цепочка `build-adapted → wire` без `build-catalog` оставит карточки без `<picture>`.
   **После замены логотипа** дополнительно `python3 tools/build-favicon.py` — иначе
   иконки останутся от прежнего знака. **После замены фото входа** (оно в `og:image`) —
   `python3 tools/build-og-image.py`; имя файла при этом лучше сменить, потому что
   Telegram кэширует превью по URL.
2. **После любой правки `workshops.json`** — `python3 tools/build-catalog.py`.
   Карточки и `catalog.js` генерируются из JSON; ручная правка `index.html` затрётся.
   Версия `catalog.js?v=<sha1>` обновляется генератором сама.
3. **После правки `styles.css` / `main.js` — поднять `?v=`** в `index.html`
   (сейчас css/js = 3, images.js = 1). Без этого `immutable`-кэш из пункта 1 будет
   держать старые файлы до года.
4. В `index.html` инлайн-`<style>`/`<script>` не добавлять: из-за каскада правки живут в
   `assets/css/styles.css` и `assets/js/main.js`. **Исключения:** однострочный
   feature-detect `html.js` + 3-секундный `reveal-fallback` в `<head>` — он обязан
   выполниться до первой отрисовки, и `<script type="application/ld+json">` — данные
   для поисковика, они обязаны быть в HTML. Порядок блоков в CSS менять нельзя — файл
   склеен из четырёх исторических блоков, поздние перебивают ранние.
5. **Новая страница в корне** — добавить её URL в `sitemap.xml` и `rel="canonical"`
   в её `<head>`; без этого страница выпадает из карты сайта, а версии с `www`
   и без считаются разными адресами.
6. Файлы проекта правятся и вне этой сессии (обнаружено: содержимое менялось между ходами,
   размеры файлов сохранялись). Перед правкой — перечитывать, а не полагаться на прошлый отчёт.

## известные неточности первоначальной диагностики

Оставлены здесь, чтобы их не «исправляли» заново:

- Тезис «у JS-картинок нет `width/height` → CLS» неверен: контейнеры `.work-visual`/
  `.detail-visual` имеют фиксированную высоту CSS, измеренный CLS = 0.00002.
- Тезис «крестик удаляет модалку через `.remove()`» относился к версии кода, которой к моменту
  правок уже не было.
- 98%-ая «дельта скриншотов» при сравнении до/после оказалась шумом ленивой загрузки:
  контрольная пара скриншотов одной версии даёт 0, и сравнение пересняли с отключёнными
  анимациями и принудительно `eager`.
