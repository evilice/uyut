# Новогодние макеты сайта «УЮТ»

PNG-макеты трёх вариантов новогоднего оформления. Код сайта (`index.html`,
`assets/css/styles.css`) не менялся: макеты — отдельные HTML-страницы, где декор
наложен поверх текущей вёрстки. Палитра (зелёный / кремовый / золото) и шрифты
(Cormorant Garamond + Manrope) сохранены во всех вариантах.

## Варианты

1. **«Тёплый свет»** — `variant-1.html`. Гирлянда с тёплым свечением ламп над
   hero, боке и мягкий снег, снежная шапка на карточке, штамп-печать со свечением.
   Самый «ламповый» вариант: ощущение вечера при гирлянде.
2. **«Хвойный уют»** — `variant-2.html`. Еловые сприги с ягодами и шарами по
   углам, венок вокруг логотипа на карточке, крафт-бирки на бечёвке («С НОВЫМ
   ГОДОМ», «2027», «ДЛЯ СВОИХ»), пунктирный штамп. Рукотворный, домашний характер.
3. **«Морозные узоры»** — `variant-3.html`. Снежинки на нитях, морозные
   папоротники по углам, контурный «2027» в гуттере между колонками, двойная
   золотая рамка карточки, внутренние рамки и ❄-watermark в каталоге. Самый
   сдержанный и «морозный» вариант.

Общее для всех: новогодняя строка-баннер сверху и возвращённый штамп-печать на
углу карточки (на живом сайте он скрыт правилом `display:none!important`).

## Перерендер

Из корня репозитория:

```bash
python3 -m http.server 8899 --bind 127.0.0.1 &
node docs/ny-mockups/shoot.mjs
```

Нужен chromium (snap) и харнесс `tools/tests/cdp.mjs`. Скриншоты: DPR 2,
desktop 1440×900, mobile 390×844; анимации и reveal отключены инъекцией CSS.
Оркестратор может зависать на выходе после записи всех PNG (особенность
snap-обёртки chromium) — файлы к этому моменту уже готовы.
